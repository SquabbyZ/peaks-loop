新增的 src/ 与 tests/ 文件在未被 `git add` 时，仓库里两条全树不变量看不到它们：`bdd-test-style-ratchet`（读 tracked tests）与 `peaks-gate` 基线普查（`git ls-files`）。于是 scoped 测试全绿、`peaks-gate.mjs repo` 也 exit 0，一旦暂存就变红。做法：声称"全树通过"之前，先 `git add -A` 再跑 tree 级三套（`tests/unit/standards`、`tests/unit/lint`、`tests/unit/*.test.ts`），跑完 `git reset` 撤销暂存。
