新增文件后 `file-size-cap` / `scope-shadow-coverage` / `silent-warning-scope-leg` 会因缺少 `files[]` 行而红，正确做法是 `git add -A` 后跑 `node .husky/peaks-gate-baseline.mjs`。但这有抬 ceiling 的风险，所以：让 RD 改代码、由编排器自己做重生成，并在重生成前后逐字段比对 `ceilings`（我这次用 node 读两个 JSON 比较，得到 `ROSE: []`，生成器也自报 "every ceiling held — nothing rose"）。BDD ratchet 是例外：新增违规不能靠重生成记录，必须改测试。
