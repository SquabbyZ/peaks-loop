图谱 → 重建 HTML → 用自写静态解析器复算 → 比对，这条往返由构造保证自洽，证明不了重建页真的保持关系。实测反例：预览的 `<html>` 盒子是 0×0，采集把它丢掉，祖先角色链少一层，所有编号都变——静态解析完全看不出来，真实浏览器一跑就暴露。凡是"重建/往返/还原"类断言，至少要有一次真浏览器或真解析器的独立复现。
